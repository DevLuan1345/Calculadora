## 🧮 Calculadora Web

Este projeto é uma calculadora web interativa, desenvolvida com foco em praticar os fundamentos do desenvolvimento front-end utilizando HTML, CSS e JavaScript. A aplicação simula uma calculadora tradicional, permitindo realizar operações matemáticas básicas de forma rápida e intuitiva diretamente no navegador.

O layout foi inspirado em calculadoras modernas, com um design elegante, botões bem distribuídos e uma interface limpa que melhora a experiência do usuário. Além disso, o projeto foi estruturado para funcionar de forma responsiva, adaptando-se a diferentes tamanhos de tela.

A aplicação foi publicada utilizando o GitHub Pages, que permite hospedar sites estáticos gratuitamente a partir de um repositório, facilitando o compartilhamento e acesso ao projeto online.

## 🚀 Funcionalidades

- ➕ Operações matemáticas básicas (adição, subtração, multiplicação e divisão)
- 🔢 Inserção de números e caracteres em tempo real
- 🧹 Botão de limpar (AC)
- 🔄 Função de inverter sinal (+/-)
- 🟰 Cálculo do resultado com botão "="
- 📱 Interface responsiva e adaptável

## 🎨 Interface

- Design inspirado em calculadoras modernas
- Botões organizados em grid
- Cores diferenciadas para ações (operações, números e funções)
- Display amplo para visualização dos cálculos

## 🛠️ Tecnologias utilizadas

- HTML5 🟧
- CSS3 (Grid Layout) 🟦
- JavaScript 🟨

## 📱 Objetivo

O principal objetivo deste projeto é praticar lógica de programação e manipulação do DOM, além de desenvolver habilidades na criação de interfaces interativas e responsivas.
